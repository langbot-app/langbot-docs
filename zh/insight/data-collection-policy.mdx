LangBot 向配置的 LangBot Space 服务（默认为 `https://space.langbot.app`）发送遥测，用于了解使用情况和改进可靠性。**遥测默认开启，可以关闭。** 功能执行记录复用现有遥测，不再使用独立 Beta 诊断上报。

## 现有产品遥测

启用后，现有查询链路可能发送：

| 数据 | 内容 |
|---|---|
| 标识与环境 | `instance_id`、`workspace_uuid`、随机 `query_id`、版本、适配器及运行器类型 |
| 查询统计 | 模型名称、耗时、时间戳、管道插件名称 |
| 功能使用 | 按来源分类的工具调用次数、工具调用轮数、知识库与检索条目数、知识引擎插件 ID、沙箱执行/错误次数、已激活技能名称、已配置 MCP 服务器名称 |
| 错误 | 旧 `error` 字段可能包含原始 traceback，包括异常文本 |
| 托管运行实例活动 | 托管 SaaS 查询中的 `runtime_instance_id` 用于刷新空闲超时活动，不写入分析事件记录 |

功能计数不会主动包含工具参数/结果、检索文本或沙箱代码/输出。**但旧异常文本以及用户自定义的模型、技能、MCP 名称可能含有敏感信息。功能执行记录的内容限制不会为这条旧数据流脱敏。** 不应将现有遥测视为保证不含用户内容。

活跃工作区会在启动后不久、此后每天发送工作区心跳，包含部署平台、数据库/向量数据库类型、沙箱配置与可用性、已启用适配器类型和资源数量，而非资源内容或连接信息。

自愿参与的应用内问卷会发送问卷 ID、提交的回答、实例 ID、版本及完成/关闭状态。问卷回答是用户主动提供的内容，不属于 Beta 诊断。

## 功能执行遥测

功能执行遥测记录平台事件、路由、Pipeline / Agent / 插件事件处理器和平台 API 的执行事实，包括固定的操作标识、适配器和运行器类型、处理模式、结果、次数、首次及末次观测时间、实例与工作区标识、版本及模拟执行标记。Core 在内存中有界合并，再由后台发送；Space 负责路径覆盖分析。

这些执行记录不包含消息、提示词、模型回复、平台用户或群组 ID、工具/API 参数或结果、凭据及原始异常堆栈。实例与工作区标识可能关联到部署或账户，不应视为不可识别。此内容限制仅针对功能执行记录，不改变上述既有查询遥测的数据范围。

### 单事件执行链路

抽样上报的执行记录还可以还原单个事件的处理全过程：一个不可反推的随机链路标识、按顺序记录的阶段（平台事件 → 路由决策 → Pipeline / Agent / 插件事件处理器 → 平台 API 调用）、每个阶段的结果、路由目标标识、执行该事件的 Runner 运行标识，以及链路关闭原因。各字段与其他执行记录一样只使用代码定义的标识；路由目标以 `type:uuid` 形式上报，不使用用户自定义规则名。Core 对单条链路的阶段数和同时在途的链路数都设置了上限，超出的部分会被丢弃。

链路抽样由 `space.execution_trace` 控制：`off`、`failures`（保留含失败、取消或超时阶段的链路）、`sampled`（默认，在上述基础上保留每 N 条成功链路中的一条，N = `space.execution_trace_sample`）与 `all`。WebUI 调试执行始终保留，并继续标记为模拟执行，不计入真实执行统计。

网络不可达、超时或服务端错误不会阻断正常操作，失败详情仅记录在 DEBUG 日志中。队列有上限，故障时记录可能丢失。执行记录用于辅助分析，平台 API 返回成功不代表用户已阅读消息。

## 存储与保留

数据存储在所配置的 Space 服务。功能执行原始记录按 30 天保留窗口定期分批清理；服务中断或积压可能延迟删除。该期限不改变既有查询遥测、问卷、账户或服务日志的保留规则。覆盖分析仅供获授权的遥测管理用户或服务客户端访问。

关闭遥测会停止后续上报，但不会删除服务端已有记录。如需处理历史数据，请联系 [hello@langbot.app](mailto:hello@langbot.app) 或所用 Space 的管理员。

## 关闭遥测

在 `data/config.yaml` 的现有 `space` 节点中设置以下值，保留其他配置，然后重启 LangBot：

```yaml
space:
  disable_telemetry: true
```

此开关统一关闭查询统计、心跳和功能执行遥测，也会关闭问卷获取。使用 YAML 布尔值，不要加引号。恢复默认开启状态时，改回 `false` 并重启。

如果部署设置了 `SPACE__DISABLE_TELEMETRY`，该环境变量会在启动时覆盖文件设置；请同时修改或移除它。容器环境变量改变后需要重新创建容器。Cloud 由实例运维方配置，对该实例所有工作区生效。此设置不影响机器人正常运行，也不修改消息平台、模型提供商或插件自身的隐私设置。

参见[系统环境设置](../deploy/settings)。
