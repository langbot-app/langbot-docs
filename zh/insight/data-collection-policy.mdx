LangBot 向配置的 LangBot Space 服务（默认为 `https://space.langbot.app`）发送遥测，用于了解使用情况、改进可靠性。**现有产品遥测与 Beta 诊断是两条独立的数据流。** 本页说明 Core 4.11.0-beta.2 的诊断协议 v1，不改变现有产品分析设置。

## 现有产品遥测

启用后，现有查询链路可能发送：

| 数据 | 内容 |
|---|---|
| 标识与环境 | `instance_id`、`workspace_uuid`、随机 `query_id`、版本、适配器及运行器类型 |
| 查询统计 | 模型名称、耗时、时间戳、管道插件名称 |
| 功能使用 | 按来源分类的工具调用次数、工具调用轮数、知识库与检索条目数、知识引擎插件 ID、沙箱执行/错误次数、已激活技能名称、已配置 MCP 服务器名称 |
| 错误 | 旧 `error` 字段可能包含原始 traceback，包括异常文本 |
| 托管运行实例活动 | 托管 SaaS 查询中的 `runtime_instance_id` 用于刷新空闲超时活动，不写入分析事件记录 |

功能计数不会主动包含工具参数/结果、检索文本或沙箱代码/输出。**但旧异常文本以及用户自定义的模型、技能、MCP 名称可能含有敏感信息。新的无内容诊断规则不会为这条旧数据流脱敏。** 不应将现有遥测视为保证不含用户内容。

活跃工作区会在启动后不久、此后每天发送工作区心跳，包含部署平台、数据库/向量数据库类型、沙箱配置与可用性、已启用适配器类型和资源数量，而非资源内容或连接信息。

自愿参与的应用内问卷会发送问卷 ID、提交的回答、实例 ID、版本及完成/关闭状态。问卷回答是用户主动提供的内容，不属于 Beta 诊断。

## Beta 诊断 v1 — 4.11.0-beta.2

Beta 诊断**仅在 Beta 版本默认开启**；稳定版、alpha 和 rc 版本不启用该发送器，本次发布不提供稳定版主动开启选项。不增加配置向导、同意弹窗或必做测试步骤。采集在后台运行，队列、批次、超时和重试均有上限；诊断服务不可用不应阻塞正常使用。队列限制或网络故障可能导致诊断记录丢失。

诊断仅记录已埋点操作中白名单允许的、不含业务内容的元数据：

- Core/SDK/公开插件或运行器版本、构建 revision、部署/环境类别，以及支持或已配置的能力。
- 操作和事件类别、处理器类型、执行阶段、观测结果、次数和耗时。
- 固定原因码、错误类别及由代码标识生成的指纹，**不使用异常消息或原始 traceback**。
- 相互独立的 `instance_id` 与可选 `workspace_uuid`，以及用于关联步骤的不透明事件/trace/span/run 标识。实例级事件可能没有工作区。
- 生成、确认接收、重试、丢弃等发送器健康计数。

**这些是假名化标识，而非匿名数据。** 实例和工作区是不同的身份维度，不能互相替代；标识可能关联到账户或部署。“未经认证的报告者”不代表无法识别。

### Beta 诊断记录不包含什么

不包含消息、提示词、模型回复、原始平台事件、工具/API 参数或结果、表单值、文件/媒体内容、文件名或本地路径、原始 URL/查询字符串、凭据、平台用户/群组 ID、用户自定义资源名、原始异常或 traceback。使用公开组件 ID 和固定操作类别，而非任意文本。网络基础设施为传输和防滥用必然会接触发送者 IP；这不表示所有服务访问日志都不含 IP。

诊断用于发现已观测路径中的兼容性问题和回归，与查询使用量、留存/漏斗统计、账户绑定及托管实例空闲超时活动分离。平台 API 接受请求**不等于**用户已收到或读到消息。没有记录或尚未测试的路径不能视为成功。

## 存储与保留

发送到默认服务的数据存储于为 LangBot Space 运维的服务器，管理员、获得明确遥测访问授权的成员及获授权的服务 API 客户端可以读取 Beta 诊断；普通工作区成员身份本身不授予此权限。**服务器默认清理阈值为诊断明细 30 天、聚合数据 90 天**，配置以这些期限为上限。记录达到阈值后具备删除条件，由定期运行的工作线程分批、有界地清理；积压或服务中断可能延迟删除，并非保证在某个精确时刻完成删除。这些期限仅适用于新诊断数据流，不追溯改变现有产品遥测、问卷、服务日志或账户记录的保留规则；现有遥测继续使用既有产品分析保留设置。

退出设置生效后，停止后续诊断发送并清空本地待发送诊断记录，**不会**删除服务器已经接收的历史记录。如需删除历史数据，请联系 [hello@langbot.app](mailto:hello@langbot.app) 或所用 Space 的管理员；账户状态正常的管理员及获授权的服务 API 客户端可按实例及适用的工作区范围删除诊断。仅有遥测读取权限不能删除数据或更改错误状态。请私下提供标识，不要贴到公开 Issue 中。

## 退出方式

仅关闭 Beta 诊断：在 `data/config.yaml` 现有的 `space` 部分更新以下设置，保留其他配置，然后重启 LangBot：

```yaml
space:
  disable_beta_diagnostics: true
```

这不会改变查询遥测、心跳、问卷或其他产品分析设置。

关闭 Core 遥测（包括 Beta 诊断）：使用总开关，然后重启：

```yaml
space:
  disable_telemetry: true
```

总开关优先于 Beta 设置，也会关闭现有查询/心跳发送和问卷获取。请使用 YAML 布尔值（`true`/`false`），不要加引号。如果部署设置了 `SPACE__DISABLE_BETA_DIAGNOSTICS` 或 `SPACE__DISABLE_TELEMETRY`，启动时环境变量会覆盖文件设置；请同时修改或移除这些变量，然后重启进程（修改容器环境变量时需重新创建容器）。诊断还要求配置 `space.url`；带本地版本标记的构建（如 `4.11.0b2+local`）不会启用发送器。这些开关不会停用机器人，也不会修改消息平台、插件、模型提供商或其他在线服务的隐私设置。

## 可选 Beta 测试清单 — 4.11.0-beta.2 / v1

使用测试机器人、测试工作区和非敏感示例数据，只测试已安装适配器及插件支持的能力。本清单完全可选；诊断不会自动执行这些操作。

| 场景 ID | 检查内容 |
|---|---|
| `B2-01` | 启动/重启安装，检查平台和 Runtime 连接，并完成一次正常回复。 |
| `B2-02` | 分别触发匹配和不匹配的路由；按实际配置分别测试 Pipeline、Agent 和插件事件处理器。 |
| `B2-03` | 调用已配置的工具/插件/MCP 并回复，人工核对实际目标和内容。 |
| `B2-04` | 在安全测试环境取消运行或复现已知故障，确认机器人仍可继续使用。 |
| `B2-05` | 如支持，测试流式回复及交互回调，检查部分回复、超时和恢复行为。 |
| `B2-06` | 如需检查诊断开关，关闭诊断、重启并确认机器人正常使用；维护者可另行核实没有新诊断请求且待发送记录已清空。 |

不要为了产生诊断样本而在生产环境踢人、禁言、删除或修改用户/数据。反馈时提供场景 ID、准确的 Core/SDK 版本、平台、大致 UTC 时间、预期与实际表现，并区分真实平台与 WebUI 调试。主动提交日志/截图前去除秘密和个人信息。修复后在新构建上重复同一场景。诊断覆盖只能补充这些检查，不能替代人工验证。
